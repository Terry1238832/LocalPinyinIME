# 前文联想与智能续词

0.7.0增加两种本地辅助：继续输入拼音时，参考光标前的文字给同音候选排序；词语上屏后，显示可以接着输入的词语。例如输入“我想”后，可以从联想中接“去”“看看”等，再继续输入拼音。

联想出现时，按Tab接受当前联想项，或用鼠标点击候选。Esc关闭联想。空格、数字、回车、退格和光标键继续执行普通编辑操作；字母直接开始下一段拼音。已开启的Shift切换与Ctrl＋Space继续有效。宿主自己绘制候选时，Tab接受宿主选中的联想项。

在设置的“输入”页面可以关闭“前文联想”。同页的试用区提供前文、后续拼音和真实引擎结果；点后续词只追加到试用区，可以反复尝试。开关关闭时，试用区仍可查询。

联想使用346条原创关系、内置词语和个人词库的短语补全，以及已有选词学习中的短语。它适合常用表达与下一词补全，长篇内容仍由用户继续输入和选词。有些前文没有合适的联想，直接继续打拼音即可。

前文来自当前光标前最多32个UTF-16单位，以当前连续汉字作为参考。标点、换行和英文边界结束前一个汉字段；光标移动、正文改变、失焦或切换输入窗口会关闭旧联想。非空选区、只读输入、密码输入或宿主无法提供前文时，保留普通拼音输入。

前文查询在本机内存中完成，试用与接受联想不会新增学习记录；正常拼音选词沿用原来的本地学习机制。清除学习仍保留个人词库和设置。
