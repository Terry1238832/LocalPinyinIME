# 前文排序与联想

本地拼音有两种和“前文”相关的功能，0.8.0 起把它们分开：

## 根据前文排列候选（始终开启）

输入拼音时，引擎读取光标前最多 32 个字符，以当前连续汉字段作为参考，用字符 4 元语言模型给同音候选排序。例如“他跑”之后输入 de，首选“得”；“这起”之后输入 shijian，首选“事件”；“没有”之后输入 shijian，首选“时间”。语言模型和测量结果见 [前文语言模型](CONTEXT_MODEL.md)。

有些应用不向输入法提供光标前文字（读取失败或总是空）。这时引擎使用本输入法刚在同一输入框里上屏的文字作为参考；它只保存在内存里，两分钟未输入、切换窗口、移动光标或使用编辑快捷键后即失效，不写入磁盘，也不用于密码输入框。

## 联想下一个词（默认关闭）

词语上屏后，可以显示接下来可能输入的词：按 Tab 接受当前选中的联想，Esc 关闭；空格、数字、回车、退格和光标键继续执行普通编辑。0.7 版本默认开启这一功能，0.8.0 起改为可选，在设置的“输入”页面打开“联想下一个词”。0.7 保存的旧设置不会自动打开它。

联想使用 346 条原创关系、内置词语和个人词库的短语补全，以及已有选词学习中的短语。

## 试一试

设置“输入”页面的试用区可以填写前文和拼音，同时显示“参考前文”和“不参考前文”两组候选，以及联想结果。试用区不写入学习记录；联想开关关闭时也可以使用。

前文查询都在本机内存中完成。非空选区、只读输入或密码输入不会读取前文。
