本地拼音使用原生 Windows TSF：COM DLL 接收输入事件，通过系统编辑会话更新和提交组合文字；候选使用自绘窗口或宿主管理的 TSF UIElement。

engine 负责离线词库、有限宽度整句解码、简拼/补全/容错与本地学习；settings 负责现代 Win32 设置页；setup 负责系统注册、用户启用与验证。CMake 共享静态库在产品和测试之间复用，无联网模块。


0.5.0 使用四份运行数据：项目基础词库、项目扩展词库、独立授权的标准词库和 1–4 字字符上下文统计。标准层为已经存在的项目词提供整句解码参考频率，保留项目的直接候选分数和个人词库覆盖。有限宽度搜索组合词语，根据完整文本上下文、词项可信度、明确拼音边界和个人学习排序；不依赖在线服务或大模型运行时。

短前缀补全和简拼使用按需索引及缓存；个人词库编辑会使相关索引失效。长句保留前部候选，选中后在同一 TSF 上下文继续编辑剩余拼音。标点提交当前候选并在光标处插入中文符号；组合达到长度上限时提交安全片段后继续接收下一键。

设置与候选窗共享 Direct2D/DirectWrite 渲染，同时保留原生按钮、开关、文本框和列表的焦点、键盘及辅助功能语义。只使用 Windows 系统图形库和字体。截图工具为开发验证产物，不进入安装包。
