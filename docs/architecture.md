本地拼音使用原生 Windows TSF：COM DLL 接收输入事件，通过系统编辑会话更新和提交组合文字；候选使用自绘窗口或宿主管理的 TSF UIElement。

engine 负责离线词库、有限宽度整句解码、简拼/补全/容错与本地学习；desktop 负责Electron/React设置页，settings提供共用配置与词库目录；setup 负责系统注册、用户启用与验证。CMake 共享静态库在产品和测试之间复用，无联网模块。


0.7.3 使用五份运行数据：项目基础词库、项目扩展词库、独立授权的标准词库、1–4字字符上下文统计与原创前文→后续词联想关系。标准层为已经存在的项目词提供整句解码参考频率，保留项目的直接候选分数和个人词库覆盖。有限宽度搜索组合词语，根据完整文本上下文、词项可信度、明确拼音边界和个人学习排序；不依赖在线服务或大模型运行时。

短前缀补全和简拼使用按需索引及缓存；个人词库编辑会使相关索引失效。长句保留前部候选，选中后在同一 TSF 上下文继续编辑剩余拼音。标点提交当前候选并在光标处插入中文符号；组合达到长度上限时提交安全片段后继续接收下一键。

原生候选窗继续使用Direct2D/DirectWrite，按文字测量、字号、DPI和显示器可用宽度分页，拼音、当前页候选、页码和按钮同在一行。TextService保存完整候选索引和页边界，数字按当前页映射，长词仅在显示时省略，提交保留完整文字；TSF UIElement共享这套页状态，接受宿主的有效页边界。宿主回调只同步服务状态和自绘窗口，避免反向UpdateUIElement导致同步递归。

React设置页由Vite编译为本地资源，Electron只加载app://local。预览根据容器和实际文本宽度单行分页，保留完整原生候选。隔离preload只提供固定API；主进程校验消息来源和参数，再无shell启动原生桥接。桥接复用SettingsStore、UserLexicon和PinyinEngine。写操作串行并使用跨进程锁，读取和预览不创建词库或学习文件。Electron仅在设置程序打开时运行。

个人词条保留明确来源标志。长条目频率达到建议值5000且完整拼音键匹配时，进入直接候选通路，避免被句子搜索剪掉；低频、部分拼音和普通系统长句保留上下文排序。编辑和删除恢复此前词库层的分数与来源。

TSF在首个拼音键前以同步只读编辑会话读取当前光标前32 UTF-16，先检查选区、只读与密码输入scope。上屏后ContinuationModel查询最长匹配的关联规则、词库和已选短语前缀；只在Tab或显式候选接受时插入后续文字。保存caret range，并以编辑/线程焦点sink与接受前复核关闭旧联想；普通编辑键透传。新增输入开关沿用同一settings.json，配置广播即时关闭预测。
