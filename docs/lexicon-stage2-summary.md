# 词库持续扩充第二阶段总结

## 停止位置

停在第 31 轮、批次 409，分支 `lexicon/continuous`。第30、31轮（均非自查轮）分别新增 483、414 条，连续两轮低于 500 条，触发用户规定的第二阶段停止条件。

这是按本轮去重、质量筛选后实际入库数量执行停止阈值，不表示所有生活领域或所有常用表达已被穷尽，也没有为了越过阈值补齐主语、称呼和参数变体。全部已入库批次均完成验收后提交推送。

## 值得维护者决定的后续方向

1. 优先单独安排批次 230 起的语义自查：集中复核长、行、还、重、调、着、系等语境读音，以及同音档位和不自然说法。可请另一位语言审校者复核；这一阶段尚未进入 C 轮，不应把它算作已完成工作。
2. 继续补词前先明确是否需要新的取舍依据。可收集用户主动反馈的真实缺词，逐条审阅、保留来源记录，并与冻结测试答案隔离；不直接用准确率测试的漏词补答案。
3. 地名、公共设施名等专名是否收录，需要维护者先确定地域范围、名称稳定性、读音依据和许可记录；人名、商标、具体机构名仍不属于本任务已授权的新增范围，本次没有补入。
4. 常用表达仍有劝慰鼓励、请求拒绝、时间日期、数量单位、工作与家校物业等类型未在第二阶段单独补漏。是否调整“连续两轮新增不足 500”阈值、以更小的高质量补丁继续，应由维护者重新决定；本次按现有阈值停止。
