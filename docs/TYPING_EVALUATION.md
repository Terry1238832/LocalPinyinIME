## 逐键测量

固定集从每句首字母逐键增长，合计4477次查询；本次构建首键18.095 ms，中位数7.384 ms，95百分位22.453 ms，最大51.547 ms。旧集中索引的同类首键曾为289.036 ms；首字母分区避免首键解析整个词库。

这些耗时只包含引擎查询，未包含Windows键盘路由、TSF编辑会话和宿主绘制时间，且受当前机器状态影响。真实TSF集成测试另行覆盖候选提交、前缀保留、中文标点和超长组合边界；它不等于所有应用的安装后验收。

## 复现

普通构建无需联网或作者依赖。离线生成模型：

```powershell
python tools/build_context_model.py --corpus-dir resources/dictionary/authoring --exclude-cases tests/data/typing_holdout.tsv tests/data/typing_fresh.tsv tests/data/typing_independent.tsv --output resources/dictionary/context_zh.tsv
```

构建后运行引擎验证：

```powershell
python tools/evaluate_typing.py --engine .build/bin/LocalPinyinImeEval.exe --resources .build/bin --cases tests/data/typing_holdout.tsv --output .build/evaluation/reproduced.json --keystrokes
```

另外两组分别替换为 typing_fresh.tsv、typing_independent.tsv。0.4.0与0.5.0使用此前发布的源码引擎及相同验证工具。摘要、失败案例、引擎、四份运行资源和输入文件SHA-256见 [typing-evaluation.json](typing-evaluation.json)。早期0.4.0/0.5.0记录只包含当时已记录的哈希字段。
