# 输入质量与逐键耗时

0.5.0 使用与 0.4.0 相同的输入和期望文本比较。每次验证使用独立临时个人词库与学习记录，不学习期望答案。首选正确要求整句逐字匹配；前九项覆盖要求其中一项与期望整句完全相同。字符错误率使用首选文字的编辑距离除以期望汉字数。

| 验证集 | 版本 | 首选整句正确 | 前九项包含正确整句 | 字符错误率 |
| --- | --- | ---: | ---: | ---: |
| 固定138句 | 0.4.0 | 7/138（5.07%） | 13/138（9.42%） | 40.13% |
| 固定138句 | 0.5.0 | 86/138（62.32%） | 116/138（84.06%） | 5.41% |
| 新取67句 | 0.4.0 | 6/67（8.96%） | 7/67（10.45%） | 52.11% |
| 新取67句 | 0.5.0 | 34/67（50.75%） | 50/67（74.63%） | 11.09% |

固定集包含《背影》《故乡》《一件小事》的47个片段及91句原创日常文本。本轮曾用它调试和比较方案，属于固定回归验证集，不能称为盲测。0.5.0 的固定日常子集为67/91首选正确（73.63%），84/91前九项覆盖（92.31%）；文章子集为19/47首选、32/47前九项覆盖。

新取集在模型方案确定后准备，包括[《荷塘月色》](https://zh.wikisource.org/zh-hans/荷塘月色)前三段按标点连续切分的47个片段及20句原创日常文本；没有按引擎结果挑选片段。新取日常子集为12/20首选正确（60%），19/20前九项覆盖（95%）；文章子集为22/47首选、31/47前九项覆盖。它与固定集的难度和样本大小不同，不能混用两个百分比。

这四部完整作品均不进入训练语料；两份验证集的完整期望句也从语料生成中排除。训练仅生成1–4字统计，不将测试整句追加为词库答案。词库扩充后新取日常首选有一例变化，记录的是最终安装包对应的真实结果。长句、同音词、人名、罕见文学词仍可能需要选词或分段确认。

## 逐键测量

固定集从每句首字母逐键增长，合计4477次查询；最终构建首键11.555 ms，中位数3.268 ms，95百分位11.097 ms，最大26.243 ms。旧集中索引的同类首键曾为289.036 ms；首字母分区避免首键解析整个词库。

这些耗时只包含引擎查询，未包含 Windows 键盘路由、TSF 编辑会话和宿主绘制时间，且受当前机器状态影响。真实 TSF 集成测试另外覆盖候选提交、前缀保留、中文标点和超长组合边界；并不等于所有应用的安装后验收。

## 复现

普通构建无需联网或作者依赖。生成模型可运行：

```powershell
python tools/build_context_model.py --corpus-dir resources/dictionary/authoring --exclude-cases tests/data/typing_holdout.tsv tests/data/typing_fresh.tsv --output resources/dictionary/context_zh.tsv
```

构建后运行引擎验证：

```powershell
python tools/evaluate_typing.py --engine .build/bin/LocalPinyinImeEval.exe --resources .build/bin --cases tests/data/typing_holdout.tsv --output .build/evaluation/reproduced.json --keystrokes
```

新取验证替换为 `tests/data/typing_fresh.tsv`。0.4.0 对比使用此前发布的源码引擎与相同验证工具。完整摘要、失败案例、引擎和输入文件SHA-256见 [typing-evaluation.json](typing-evaluation.json)。
