# 词库覆盖率评估（0.8.1）

内置词库共 209,306 条（核心、常用、标准三层合计）。下面从字、常用词、真实文本三个角度估计覆盖率；数据由 `tools/report_lexicon_coverage.py` 生成，完整结果见 [lexicon-coverage.json](lexicon-coverage.json)。

## 1. 常用字：《通用规范汉字表》8105 字

按国家标准读音（Unicode Unihan `kTGHZ2013`，lüe/nüe 按输入法习惯写作 lue/nue）能否作为单字候选打出：

| 级别 | 字数 | 可按标准读音打出 | 覆盖率 |
| --- | ---: | ---: | ---: |
| 一级（常用字） | 3,500 | 3,485 | 99.6% |
| 二级 | 3,000 | 2,347 | 78.2% |
| 三级（姓氏、地名、科技用字等） | 1,605 | 225 | 14.0% |

一级字缺的 15 个几乎都是只在固定词里出现的字，如 蚣（蜈蚣）、蚪（蝌蚪）、蜻（蜻蜓）、蝙（蝙蝠）、豌（豌豆）。整词照样能打，只是不能单独按单字选出。二、三级缺字多为生僻字（丏、仉、艽、邙……），影响罕见的人名、地名和古籍用字。

## 2. 常用词：按词频排名

以 jieba 词频表（MIT）为参照，取两字及以上的词按频率排序：

| 范围 | 已收录 |
| --- | ---: |
| 前 1,000 | 98.9% |
| 前 5,000 | 95.9% |
| 前 10,000 | 91.3% |
| 前 30,000 | 74.0% |
| 前 50,000 | 59.7% |
| 前 100,000 | 36.9% |

前一万里没收录的 870 个词分两类：一类是专有名词和固定说法，如 中华人民共和国、全国人民代表大会、中国共产党、有利于、相当于、马克思主义、天安门广场；另一类是 jieba 词表自带的小说人名和古代官职，如 袁承志、李莫愁、礼部、刑部，并不常用。

**收录 ≠ 能打出。** 没收录的词仍可由字和短词组句：这 870 个词单独输入时，67.4% 出现在前九个候选里，37.6% 是首选。上面那些常见专名（中华人民共和国、有利于、新冠、特朗普、全国人民代表大会、一个个）实测都是首选。

## 3. 真实文本

把留出的句子用 jieba 分词，统计两字及以上的词（按出现次数计 / 按不同词计）：

| 文本 | 词次 | 词次覆盖 | 词种覆盖 |
| --- | ---: | ---: | ---: |
| Tatoeba 日常句子 | 10,085 | 90.8% | 80.8% |
| 留出评测句（Tatoeba + Common Voice） | 13,800 | 83.3% | 70.5% |
| 中文维基新闻 | 52,264 | 85.3% | 64.6% |

这里的“未收录”有相当一部分是 jieba 合在一起的组合（我会、回家吧、谢谢您、是因为、受够了），输入法会拆开组句，不影响打字。真正缺的主要是：

- **新闻人名、时事词**：特朗普、拜登、奥巴马、新冠、冠状病毒、金正恩、李克强、赖清德；
- **港台用语**：立法会、立法院、捷运、新台币、录得、介乎、本港、港府；
- **专业和外国地名**：禾本科、蛱蝶、巴伐利亚州、阿肯色州、波多黎各。

## 结论

日常打字的覆盖已经比较充分：一级常用字 99.6%，最常用的 5,000 个词 95.9%，日常句子九成的词直接在词库里。按实际打字效果衡量更有说服力：逐词输入（参考前文）时正确词出现在前九候选的比例是 98.0%，首选是 85.7%（见 [前文语言模型](CONTEXT_MODEL.md)）。

主要短板是**时事人名和新词**（词库不会自动更新）、**港台用语**和**二级以下的生僻字**。可以把评估里的高频缺词（排除小说人名）整理成一批补充词条；生僻字可以按《通用规范汉字表》二级字补全单字条目。

## 方法说明

- “收录”指词语以任意读音出现在内置词库中；不计个人词库和学习记录。
- jieba 词表的频率来自它自己的训练语料（含新闻和小说），并非中文使用频率的权威统计；数字用于看趋势，不宜当作精确值。
- 文本分词使用 jieba 默认模式；分词边界和输入法的组句方式不同，所以“真实文本”一节偏保守。
