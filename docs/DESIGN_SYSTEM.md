# 本地拼音设计规范

适用于三个界面：设置程序（Electron）、输入候选窗口（原生 Direct2D）和安装程序（原生 Direct2D）。三者共用一份设计令牌。设置程序的版面（§1、§4–§6）在 0.23 重新设计。

## 1. 设计语言

**一张划了格线的纸。** 这是一个中文输入法，界面的材质取自书写：浅色模式是微暖的纸白，配蓝墨；深色模式是蓝黑墨色。0.23 起设置程序不再用环境光、颗粒和磨砂玻璃制造深度，改为瑞士式的版面：设置直接排在纸上，用细线分隔，标题站在左侧的页边栏里；只有拿来操作的东西（预览工作台、词表、对话框）才是一张浮起一级的纸。

- **输入法自己的语汇就是标识。**
  - 侧边栏是一个候选列表：每页有序号 1–7（和 Ctrl+1–7 对应，就像数字键选候选），当前页用**用户所选的候选框风格**画出来——自适应流体是一滴液体，胶囊是实心胶囊，悬浮晶体是一枚瓷键，光标轨道是焦点线，现代活字是一道朱红短线，竖排列表是带品牌竖条的整行，翻牌是琥珀色的牌，荧光笔是一道笔触。换了候选框风格，设置程序的导航跟着换。
  - 页面标题是一次“上屏”：上方是正在组合的拼音（虚线下划线，和任何程序里正在打的字一样），末尾是品牌插入符，下面是标题。
  - 命令面板（Ctrl+K）是给设置用的候选窗口：输入拼音或文字，前九个结果有序号，按数字直接执行。
  - 侧边栏底部是语言栏：任务栏上那枚“中 / 英”方块，加上输入法是否正在使用。
  - 插图和空状态用候选窗口缩样 `MiniCandidates`。
- **不像开发者工具。** 拼音一律用正文字体，不用等宽字体（只有数据路径例外）。导航的序号是候选序号，不画成键帽；侧边栏搜索的快捷键提示只在悬停时出现。
- **按内容类型构图。**

  | 内容类型 | 版式 | 页面 |
  | --- | --- | --- |
  | 设置 | 页边栏标题加细线分隔的设置行 | 输入、英文、工具面板 |
  | 视觉调节 | 工作台（舞台加检查器）和风格卡片 | 外观 |
  | 输入法开关 | 带输入法方块的一张卡片 | 英文 |
  | 速查 | 细线分隔的两到三栏速查表：动作在左，按键在右 | 输入、英文 |
  | 数据 | 指标带加数据集（一张纸） | 词库、学习 |
  | 机制说明 | 主数字加三步流程，排在两条细线之间 | 学习 |
  | 品牌信息 | 品牌、四格事实（两条细线之间）、页边栏标题的分节 | 关于 |

- **深度来自细线和一级表面，不靠光和阴影。** 画布是纸；能操作的对象是 `surface` 的一张纸，加一道细边和极淡的 `shadow-xs`；悬浮的东西（对话框、命令面板、提示、候选窗口预览）才有真正的阴影。不用环境光、颗粒、玻璃模糊和装饰性渐变。
- **强调色只表示状态。** 品牌蓝用于选中、开启、主要操作、焦点和进度，不用来装饰；导航的选中标记用候选框风格自己的焦点色。
- **动效只交代状态的来去。** 时长 100–260 ms，缓出曲线 `cubic-bezier(0.23, 1, 0.32, 1)`，不用回弹。系统开启“减少动画”时全部关闭。

## 2. 令牌

唯一来源是 [`assets/branding/theme/design_tokens.json`](../assets/branding/theme/design_tokens.json)，由 `tools/generate_design_tokens.py` 生成两份产物：

| 产物 | 用途 | 何时生成 |
| --- | --- | --- |
| `desktop/src/tokens.css` | 设置程序的 CSS 变量 | 运行生成脚本后提交。测试 `test_design_tokens_css` 会检查它是否与 JSON 一致 |
| `localpinyin_design_tokens.h` | 候选窗口和安装程序的 `COLORREF` 常量 | CMake 配置时生成 |

```
python tools/generate_design_tokens.py --css desktop/src/tokens.css
```

浅色和深色必须定义相同的键，候选窗口的每种风格也必须定义相同的键，生成脚本会检查这一点。主题小样需要同时显示两套颜色，因此 CSS 里另有一组固定引用：`--light-*`、`--dark-*`；候选窗口色板则用 `data-cand-style` 与 `data-cand-tone` 选择（见 §7.1）。侧边栏导航也带 `data-cand-style`，所以它的选中标记直接取当前风格的 `--cand-focus*`。

设置程序自己的版面变量写在 `styles.css` 的 `:root`：页边栏宽 `--margin-column`（196）、页边栏与内容的间距 `--margin-gap`（40）、细线 `--rule` / `--rule-strong`、缓出曲线 `--ease-out-quint`。

## 3. 颜色与表面

| 角色 | 令牌 | 浅色 | 深色 |
| --- | --- | --- | --- |
| 画布（纸 / 墨） | `bg-app` | `#F4F3EF` | `#0F131B` |
| 一张纸（可以操作的对象） | `surface` | `#FFFFFF` | `#171D28` |
| 凹陷区（表头、页脚、说明里的演示） | `surface-sunken` | `#F8F7F4` | `#121721` |
| 预览舞台 | `stage` | `#EDECE7` | `#111620` |
| 输入框与选择器的轨道 | `fill-hover` | 墨色 4.5% | 灰蓝 8% |
| 正文 / 说明 / 元信息 | `text` / `text-2` / `text-3` | 纸上 16.1 / 7.0 / 4.6 :1 | 15.2 / 7.1 / 5.1 :1 |
| 强调色填充 | `accent` | `#1A6FE8`（白字对比度 4.7:1） | `#2A6FE0`（4.7:1） |
| 强调色图形与文字 | `accent-fg` / `accent-text` | `#1A6FE8` / `#1565D8` | `#4790FA` / `#7DB3FF` |

0.23 起浅色的 `text-3` 从 `#7C7F87` 加深到 `#6B6E76`：设置去掉了卡片，更多小字直接排在纸上，原来的颜色在纸上只有 3.6:1，不够 WCAG AA 的 4.5:1。

细线用半透明色（浅色 7% / 13%，深色 9% / 17%），同一个令牌放在任何表面上都成立。每一节的第一条线用较深的 `rule-strong`，节内的行之间用 `rule`；一节结束时不再画线，下一节的深线就是分界。`glow-*`、`glass`、`sidebar`、`stage-light` 仍在令牌里（工具面板和安装程序在用），设置程序不再使用。

## 4. 版式与构图

- **响应式：**
  - 内容区是容器查询的容器：页面最宽 1080，两侧留白按内容宽度缩放（28–72 px）。
  - 内容宽度达到 1180 时：外观页的检查器移到舞台右侧，学习页的主数字与流程并排，关于页的品牌与事实并排，速查表排成三栏。
  - 内容宽度不超过 920 时，检查器折成两行；不超过 760 时，页边栏标题移到各节上方，速查表和导入导出变成一栏。
  - 一行里放不下设置名和较长的选择器（例如四个切换快捷键、六档保存时间）时，选择器换到设置名下面。
  - 所有尺寸都以 DIP 为单位，所以在 100–200% 的系统缩放下保持同样比例。
- **外壳：**
  - 左侧 232 宽的侧边栏和画布是同一张纸，右缘一道细线：品牌、搜索（Ctrl+K）、分两组的导航（“输入法”：外观、输入、英文；“收藏与记录”：工具面板、词库、学习），“关于”贴在底部，最下面是语言栏。
  - 窗口按钮悬浮在右上角；内容滚动到它下面时，被 40 px 的渐隐遮罩淡出。键盘焦点滚动时留出 48 px，不会停在按钮下面。
  - 第一个可聚焦的是“跳到内容”链接，平时藏在窗口外，按 Tab 时出现。
- **页面标题：**
  - 最上方是正在组合的拼音（13 px，虚线下划线），进入页面时逐字“打出”，插入符闪两次后停住；
  - 下面是 28 px 标题（字距 −0.02 em）和一行说明（最宽 40 em）；
  - 右侧放操作按钮或保存状态。标题下面不画线。
- **节奏：**
  - 4 px 网格。页面内各段间隔 44。
  - 设置节：左侧 196 宽的页边栏放节标题（15 px 粗体），隔 40 是内容；行高至少 56，行内上下各 11。
  - 一张纸（工作台、数据集、卡片）的圆角为 16，选择器与按钮为 8。

各页构图：

| 页面 | 构图 |
| --- | --- |
| 外观 | 工作台：舞台按实际大小显示文档行和所选风格的候选窗口（固定示例），检查器分“主题小样 / 候选字号”两栏；下面是候选框风格卡片，一次四张，两侧箭头翻页，“更多”打开全部风格 |
| 输入 | 中英文切换、候选、常用场景、拼写、输入方案、辅助功能六节，最后是速查表 |
| 英文 | 本地英文输入法的开关卡片（“英”方块随开关变色），“切换”“打字”两节，速查表 |
| 工具面板 | 打开方式、剪贴板、记录三节 |
| 词库 | 一张纸：指标带（内置词语主数字配三层构成条形；个人词语数字），下面是个人词语数据集 |
| 学习 | 主数字与用量条；两条细线之间的三步流程；“学到的词”和“输入习惯”两张数据集纸；最下面是危险操作行 |
| 关于 | 图标与名称、四格事实、数据位置，然后是“导入与导出”“软件更新”“致谢”三节（页边栏标题） |

## 5. 组件

| 组件 | 规则 |
| --- | --- |

| 键帽 | 底部 1.5–2 px 实边模拟按键厚度 |
| 速查表 | 细线分隔的行：动作在左（13 px），按键在右；页边栏里是标题和适用范围 |
| 风格卡片、主题小样、候选窗口缩样 | 同 0.22，见 §7.11 |
| 统计 | 主数字用 Display 字体和等宽数字；只有一个系列时用单色条形；“数量 / 上限”用 4 px 的用量条 |

| 提示 | 底部的浮起胶囊，带成功图标，`role="status"` |
| 新手引导 | `Tour.tsx`。第一次打开（剪贴板问题之后）出现欢迎对话框：当前候选框风格的实际截图、三条基本用法、“以后再说”和“开始导览 · 5 步”。导览是不模态的聚光灯：遮罩用 `clip-path: path(evenodd, …)` 挖出圆角 12 的洞，只有洞里的控件能点；目标外圈是 `--cand-focus-bar` 的 2 px 线加 20% 晕；说明卡片 344 宽、圆角 16，放在目标旁边（侧边栏目标放右侧，其余先下后上，都放不下时放在挡住目标最少的角）。卡片顶部是可点的步骤序号（当前步用 `--cand-focus`），然后是标题、一两句说明、“试试”提示（做到后变成成功色的“已……”），底部是上一步与下一步 / 完成。键盘：← → 翻步，1–5 跳步，Esc 退出。看完或跳过记在 `localStorage` 的 `localpinyin.tour`；“关于 › 新手引导”和命令面板可以重看。图片放在 `desktop/src/assets/tour`，都是原生渲染 |

## 6. 动效

| 时长 | 用途 |
| --- | --- |
| 100 ms | 颜色变化、按下 |
| 160 ms | 悬停、页面进入（只淡入）、候选翻页淡入、行操作淡入、说明展开 |
| 260 ms | 导航选中标记滑动、对话框与命令面板、开关滑块、分页点伸缩、条形与用量条增长、引导聚光灯与卡片移到下一步 |

缓出曲线 `cubic-bezier(0.23, 1, 0.32, 1)`；设置程序不再使用 `ease-spring`。带品牌特征的动效：

- 拼音小标题逐字打出，插入符闪两次后停住；
- 预览里的插入符持续闪烁，与真实输入时一致。

所有动效都遵循 `prefers-reduced-motion`。

## 7. 候选窗口

候选窗口是产品最有辨识度的元素。0.12 起它有四种风格，0.15 起增加到八种（0.16 用翻牌、荧光笔替换了线框、墨点），用户在“外观”页选择。各风格的结构、选中反馈和材质各不相同，但共用同一套输入规则，只改变外观，不改变任何输入行为。原生窗口与设置里的预览按同一份规格绘制，单位为 DIP。

### 7.1 架构

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 共享核心 | `src/ime/candidate_styles/layout_core.*` | 测量、分页、宿主分页边界、贴靠插入点、控件位置。每页的第一项是当前候选：空格上屏它，数字键按页内序号上屏 |
| 风格表现 | `src/ime/candidate_styles/<风格>.cpp` | 每种风格一个文件，含布局（`layout_*`）与 Direct2D 绘制（`paint_*`），以及会移动的焦点标记位置（`marker_*`） |
| 风格登记 | `candidate_ui.h` 的 `CandidateStyle`、`kCandidateStyles` | 风格 ID：`rail`、`type`、`glass`、`flow`、`capsule`、`column`、`flap`、`marker`。0.15 的 `outline`、`dot` 已移除，保存着它们的设置回到默认风格。新增风格时加一个枚举值、一个文件和一组令牌；设置桥接只接受原生认得的 ID，设置程序的 `candidateStyleIds`（`desktop/src/types.ts`）列出同样的 ID |
| 窗口 | `candidate_window.cpp` | 读取设置、组装绘制状态，并把焦点标记在 140 ms 内缓出到新位置。系统关闭“动画效果”时直接到位；高对比度模式改用系统颜色，去掉所有材质 |
| 设置与预览 | `desktop/src/CandidatePreview.tsx`、`StyleGallery.tsx`、`candidate-styles.css` | 预览、缩略图、风格卡片与“全部风格”对话框。分页、竖排列表的每页行数与“自适应流体”的形态判断和原生代码使用相同规则 |

令牌：`candidate` 下每种风格一组浅色和深色色板，键完全相同（生成脚本会检查），C++ 里是 `tokens::candidate_<风格>_<主题>`。CSS 里，`data-cand-style` 元素自动取得该风格当前主题的 `--cand-*`；`data-cand-tone` 再把它固定为浅色或深色，用于主题小样。

设置：`settings.json` 的 `candidateWindow.style`。缺失时（0.12 以前的设置）用默认的“自适应流体”，无法识别的值也回退到它；风格与主题、字号互不影响。设置程序保存后广播 `LocalPinyinIME.CandidateOptionsChanged`：正在显示的候选窗口立刻换成新风格，其他程序在下一次按键读取设置时生效。

### 7.2 共同规则

| 项目 | 规格 |
| --- | --- |
| 拼音 | 音节用 `composition`，分隔符“'”用更浅的 `separator`，末尾是插入符（`caret`）。拼音过长时保留末尾；联想状态显示“联想”，不画插入符 |
| 控件 | 拼音行右端是“‹ 分页 ›”和设置齿轮。不超过三页时用分页点，当前页是 12 px 的短条，多于三页时显示“2/5”；翻页只在多于一页时出现；Microsoft Store 应用中不显示齿轮 |
| 字号 | 候选 14–24 px，共 7 档；各风格的放大倍数见下文 |
| 位置 | 拼音的左缘对齐插入点；下方空间不够时显示在插入点上方；不超出所在显示器的工作区 |
| 阴影 | 两层：紧贴边缘的主阴影和宽而淡的环境阴影，阴影边距 16。阴影只随面板尺寸重算，动画帧之间复用 |

### 7.3 光标轨道 Cursor Rail（`rail`）

精密、轻盈，像一个文字导航仪器。

| 项目 | 规格 |
| --- | --- |
| 结构 | 圆角 10，自上而下：拼音行（高 30，拼音 13 px）、候选轨道、页轨（仅多页时）。面板从 `surface-top` 到 `background` 轻微过渡，深色模式顶部有一道亮线 |
| 候选 | 沿同一条水平轨道排列：小号编号（候选字号的 0.55 倍）加候选词，所有字号共用一条基线。候选之间靠距离和字级形成节奏，不画边框；轨道是 1 px 的 `divider` 线，相邻候选之间有一道细刻度 |
| 当前候选 | 放大到 1.12 倍、粗体，背后是柔和的 `focus` 底；编号用 `focus-number` |
| 焦点线 | 2 px 的 `focus-bar` 线压在轨道上，横跨当前候选的编号和文字；指针移到别的候选上时，焦点线沿轨道滑过去，离开后滑回当前候选 |
| 页轨 | 轨道下方 2 px 的底线，当前页那一段亮起，翻页时滑动 |

### 7.4 现代活字 Modern Type（`type`）

以中文排版为核心，让汉字本身成为主角。

| 项目 | 规格 |
| --- | --- |
| 结构 | 圆角 7 的纸面，一道细边。上方是 5×5 的朱红印记和 12 px 拼音，下面一条发丝线，再下面是一行候选 |
| 字体层级 | 所有候选落在同一条基线上。当前候选放大到 1.3 倍、粗体（`focus-text`），其余用细体（300）和稍浅的 `text-muted`。编号是 Segoe UI 的小号数字，像上标一样挂在字的右上方之前 |
| 选中 | 不用底色：字号、字重、颜色加一道朱红短线（`focus-bar`，约一个字宽，2 px）。指针移到别的候选上时，短线移过去 |
| 节奏 | 候选之间约一个字的间距（至少 16）；当前候选总在每页第一位，所以不会因为字号变化推挤相邻的字 |
| 颜色 | 浅色是现代纸白配墨色与朱红；深色是深墨底、暖白字和提亮的朱红。不用宣纸、水墨或书法装饰 |

### 7.5 悬浮晶体 Floating Glass（`glass`）

浮在桌面上的实体控制面板。

| 项目 | 规格 |
| --- | --- |
| 材质 | 圆角 16。表面从 `surface-top` 向 `background` 渐暗，外圈细边，内圈一道 `inner-edge`，顶部一道 `highlight` 亮线；阴影比其他风格更深、更低，显得浮得更高。内部不画分隔线 |
| 为什么不透明 | 候选窗口是 UpdateLayeredWindow 分层窗口，无法使用实时背景模糊；半透明会让背后的网页和图片干扰文字。所以用不透明的分层材质模拟晶体，在任何背景上文字都清晰，也不增加每帧开销 |
| 候选 | 横向一行，直接放在表面上：小号编号加候选词。指针悬停时，表面在该候选下方出现一块磨砂底 |
| 当前候选 | 一枚陶瓷键帽：顶面 `focus-top` 到 `focus` 的渐变、细边 `focus-edge`、顶部一道亮线、键帽自己的接触阴影（`focus-shadow-alpha`）。按下时下沉 1 px、阴影减半。当前候选位置变化时，键帽滑过去 |
| 颜色 | 浅色是冰白与浅灰玻璃上的白瓷键；深色是烟灰玻璃上的石墨蓝瓷键 |

### 7.6 自适应流体 Adaptive Flow（`flow`，默认）

当前候选是一滴液体，会流动；窗口按候选内容自动选择形态，用户无需选择布局。

| 项目 | 规格 |
| --- | --- |
| 共同部分 | 圆角 14，顶部查询栏：一枚水滴标记（`focus-top` 到 `mark` 的渐变，带一点高光）、拼音和控件。三种形态的查询栏完全相同，拼音始终对准插入点，形态变化时窗口不会左右跳动 |
| 候选 | 不画底和框，只有半粗体小编号和候选词 |
| 水滴 | 当前候选背后的一滴液体：从 `focus-top` 到 `focus` 的竖向渐变，上半部一层白色光泽（下缘是一道缓慢的波纹），顶部一道亮线，下方一圈同色的光晕（`focus-shadow-alpha`）。它贴着文字：从候选左缘到文字末尾再多一点，至少是一枚圆胶囊；圆角取 12 与高度一半中较小的。水滴盖住的文字变成白色（`focus-text`，编号 `focus-number`），水滴半盖住一个字时，那个字也只有一半是白的 |
| 流动 | 紧凑和展开形态里，水滴流向指针下的候选；方向键换候选、打字时首选变长变短，也是流过去。前进方向的边先走（前 60% 的时间到达，略冲过头再回来），后面的边晚一点出发、缓进缓出，所以水滴先拉长、中间收腰，再聚拢成一滴；移动时光泽的波纹晃动。一次移动 380 ms。平衡形态的当前候选有自己的一行，水滴不跟指针走 |
| 出现 | 候选窗口刚出现时，水滴从左端的一个圆点倒满整个长度（340 ms）；变了的候选从下方 6 px 处淡入上浮，一个接一个（每个 220 ms，间隔 26 ms），没变的候选不动 |
| 痕迹与悬停 | 水滴流到别的候选上时，当前候选的位置留一层浅色痕迹（`focus-edge`）；平衡形态里，指针下的候选出现 `hover` 底 |
| 关闭动画、高对比度 | 系统关闭“动画效果”时没有流动、倒入和上浮；高对比度时水滴是系统高亮色的纯色块，没有光泽和光晕 |
| 紧凑 Compact | 一行候选，当前候选在最前。适合单字和短词 |
| 平衡 Balanced | 当前候选独占一行，放大到 1.17 倍，右端是提示键帽“空格”（联想时为“Tab”）；其余候选排成一行。适合中等长度或长短差异明显的候选 |
| 展开 Expanded | 每个候选一行，每页最多五行，长句折成两行后再省略。最宽 600，行数还受显示器高度限制。适合长词和整句。上下换行时水滴竖着拉长，腰收在左右两侧 |

形态判断（`decide_candidate_flow_form`，设置预览用同一套阈值）：取候选文字的实际渲染宽度（与字号、DPI 有关）、最长值、中位数和这台显示器上允许的最大行宽。

- 最长 ≥ max(9 em, 0.42 × 最大行宽) 时进入展开；已经展开时，最长 ≥ max(7 em, 0.33 × 最大行宽) 就保持展开。
- 最长 ≤ 3.2 em 且最长与中位数之比 ≤ 2.6 时进入紧凑；已经紧凑时，放宽到 4.2 em、比值 4。
- 其余为平衡。

进入一种形态需要明显的信号，保持只需较弱的信号，所以多打一个字母通常不会改变形态。删除输入、候选变短时，会在越过较低的门槛后回到紧凑。候选窗口关闭后重新判断。

设置预览用同样的规则：水滴的四条边各有自己的 CSS 过渡（前进方向的边快、带回弹，后面的边慢、晚 60 ms），里面放一份白字的候选副本，跟着水滴的左上角反向移动，所以盖住的字是白的。

### 7.7 胶囊 Capsule（`capsule`）

整个窗口是一条圆角长条，最矮的候选窗口。

| 项目 | 规格 |
| --- | --- |
| 结构 | 一行，高度为候选字号 + 20，圆角为高度的一半。左端是 13 px 的拼音（最多占行宽的四分之一，过长保留末尾），一道约 44% 高的 `divider` 竖线隔开，随后是候选，右端是分页与齿轮 |
| 候选 | 编号加候选词，每个候选是一枚胶囊形区域（左右内边距 11，上下距面板边 4）；悬停时出现 `hover` 底 |
| 当前候选 | 实心胶囊：`focus` 底（浅色和深色都是品牌蓝），白色半粗体文字（`focus-text`），编号是浅蓝（`focus-number`），下方一层淡阴影（`focus-shadow-alpha`）。当前候选变化时，胶囊滑过去 |
| 分页 | 每页能放多少放多少，分页时预留分页控件的宽度，所以满页的候选也不会被压成省略号 |

### 7.8 竖排列表 Column List（`column`）

候选一行一个，像菜单一样从上往下读。

| 项目 | 规格 |
| --- | --- |
| 结构 | 圆角 12，最宽 440。上方是拼音行（高 30，拼音 13 px，控件在右端），下面一条内缩的发丝线，留 4 的间隔后是候选行 |
| 候选 | 每行高为候选字号 + 14，行间距 2；编号与候选词左对齐，过长的候选在行尾省略。每页最多 6 行，显示器放不下时减少行数；宿主自己分页时，行高按需压缩 |
| 当前候选 | 整行 `focus` 底、`focus-edge` 描边，左缘一道 2 px 的品牌竖条，编号用强调色，文字半粗体。当前候选变化时，底色滑到新的一行 |
| 高度 | 每页都按候选最多的一页定高，翻到最后一页窗口不会变矮跳动 |

### 7.9 翻牌 Split-Flap（`flap`）

机场的航班翻牌：一个字一块牌，候选变了，牌就一块块翻过来。

| 项目 | 规格 |
| --- | --- |
| 结构 | 圆角 12 的牌板（`background`），上方 12 px 的拼音，下面一行翻页牌。每个字一块牌，所有牌同宽（按一个全角字加左右各 3 的宽度），所以整行像一块对齐的牌板；英文和数字也居中在同样大小的牌里 |
| 牌 | 高为候选字号 + 12，圆角 3，牌间距 2。上半 `surface-top`、下半 `inner-edge`，中间一道 1 px 的铰链线（`divider`）；上半的圆角在铰链处留出一个小缺口，像真实翻牌的转轴。字号即候选字号，字重 500 |
| 当前候选 | 一排琥珀色的牌：上半 `focus-top`、下半 `focus`，铰链线 `focus-edge`，字是深色 `focus-text` 半粗体，编号用 `focus-number`。悬停的候选牌面变成 `hover` / `pressed` |
| 翻动 | 候选变化时（新的输入、翻页、刚出现），只有字变了的那几块牌翻：上半片先向铰链折下，下半片再落下，每块 170 ms，沿着一行从左往右每块晚 16 ms 开始。多打一个字母时，没变的字不动，只翻新的字。系统关闭“动画效果”或高对比度时直接显示结果 |
| 长候选 | 放不下的字不显示，最后一块牌显示“…” |

### 7.10 荧光笔 Highlighter（`marker`）

一张笔记纸，当前候选用荧光笔划了一道。

| 项目 | 规格 |
| --- | --- |
| 结构 | 圆角 10 的纸面（`background` 偏暖的纸白，深色是墨灰），13 px 的拼音，下面一行候选，候选下方一道贯穿的横格线（`divider`） |
| 笔触 | 一道半透明（86%）的 `focus` 色笔触，盖住字的大部分、略偏下：从字前一点开始，过字尾再拖出约 1/4 个字。两端是斜切的扁头笔痕，边缘有轻微的起伏，起伏由词本身决定，同一个词每次都一样；再叠一道更淡、略低的第二笔，像真实的笔触重叠。笔触画在字的后面，字始终清楚 |
| 当前候选 | 笔触下的字换成深墨色 `focus-text`、字重 500；深色模式同样是亮黄笔触配深色字，不用在深色纸上变暗的半透明色 |
| 指针与动画 | 指针移到别的候选上，笔触在 140 ms 内滑过去，那个词变成深墨色；当前候选换了（新的输入、翻页）时，笔触从左往右重新划一笔（190 ms） |

### 7.11 设置里的预览

外观页顶部是风格卡片：真实结构的缩略图、中英文名称和“使用中”标记。宽窗口一次显示四张（窄窗口两行两张），两侧圆形箭头翻到另外四张，下方圆点表示第几组；用键盘或在“更多”里选中另一组的风格时，自动翻到那一组。“更多”打开“全部候选框风格”对话框：八张卡片四个一排，每张多一句特点，点选即用。

点选后立即保存。下面的舞台用固定示例（sui'bian 的十二个候选）显示所选风格，跟随当前字号和主题，可以翻页，不启动输入引擎；翻牌在翻页时一块块翻动，荧光笔重新划一笔。主题小样显示当前所选风格在浅色和深色下的样子。

## 8. 数据展示

- 单个数值用主数字或指标，不画单柱图表。
- 内置词库的三层构成用单色条形，因为只有一个系列，所以颜色只用一种：起点为直角，末端为 3 px 圆角，数值直接标在条形旁，悬停提示里给出精确占比。
- 有上限的数量用用量条：学习记录的已用条数与 2,048 条上限。
- 每页最多一个主数字。
