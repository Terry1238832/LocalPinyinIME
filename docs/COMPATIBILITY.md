# 本地拼音应用兼容性说明

本地拼音 0.7.0 的自动测试、界面检查和历史桌面测试分别覆盖不同范围。它们不构成对所有 Windows 应用或文本控件的兼容承诺。

## 0.7.0 已验证范围

本版本通过离线输入引擎、词库、学习持久化、界面布局和原生 TSF/COM 回归测试。TSF 集成测试直接加载新 DLL，使用真实 Windows 文档、上下文、组合和编辑会话，验证拼音组合、中文候选提交、前缀选词后保留未提交拼音、中文标点、超长组合边界保留后续字母与分隔符、退格、Esc 取消、Enter 提交原始拼音及英文模式透传。

该集成测试通过内存适配器处理键盘 sink 注册，不安装或注册输入法；它不验证 Windows 自动加载已安装 Profile 后的键盘路由。候选窗仍为原生组件。设置页改为Electron，使用隐藏offscreen真实Chromium窗口验证界面；最终交付ASAR通过14个流程和37张截图检查，包含前文查询、联想试用和开关持久化。80次侧栏切换中骨架和页面节点不重建，输入状态保留；这项检查没有操纵当前桌面焦点。

真实TSF另验证前文读取与上限、保护字段、Tab及宿主选中续词、普通编辑键、Shift/CtrlSpace、光标/正文/焦点变化及设置关闭即时生效。

本版本尚未完成干净 Windows 机器上的完整安装、卸载测试，也尚未完成安装后逐款第三方应用的兼容性矩阵。当前测试详情见 [verification.json](verification.json)，独立文本输入质量和逐键耗时见 [TYPING_EVALUATION.md](TYPING_EVALUATION.md)。

## 历史 0.3.39 桌面验证

项目此前的 0.3.39 开发基线记录了以下环境中的实际输入回归：

- 常见 Win32 桌面应用；
- Google Chrome；
- 微信；
- Windows 任务栏搜索。

这些记录属于此前版本和当时的应用场景，不能作为重构后 0.7.0 已完成相同安装后验收的证明。

此前在 Microsoft Store 和部分 Windows 11 沉浸式宿主中观察到：拼音组合、候选生成及 Space 提交可用，自绘候选窗可能不可见。0.7.0 仍保留这项已知兼容性限制，尚未证明在这些宿主中的候选呈现问题已修复。

## 使用范围和问题反馈

当前只支持 Windows x64，32 位应用尚未支持；完整支持所有第三方编辑器、浏览器、IDE、富文本控件或沉浸式宿主仍未得到验证。实际行为可能随 Windows、应用版本和文本控件变化。

出现无法输入或候选窗不可见时，可以按 Win + 空格切回其他输入法，关闭并重新打开应用；需要观察候选时可在普通桌面应用中重试。

报告兼容问题时，请提供 Windows 版本、应用名称和版本、候选窗是否可见、Space 是否能提交，以及最短复现步骤。不要提交真实输入正文、密码、个人词库或学习记录。
