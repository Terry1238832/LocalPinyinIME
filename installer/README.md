安装器封装原生输入核心、注册助手、设置桥接、四份输入数据及Electron设置程序和必需运行时，保留项目与第三方许可。运行 `scripts/Build.ps1` 完成原生测试、React/Vite编译和Electron封装，再生成版本配置并编译此Inno Setup脚本。

机器级 TSF 注册使用管理员权限；用户启用与验证通过原始用户运行。32 位应用（如 QQ 音乐）只从 32 位注册表视图加载输入法，所以包内另有 `x86\LocalPinyinIME.dll` 和 32 位的注册工具：安装时先由它在 32 位视图中注册并验证，再注册 64 位输入法（共享的输入法配置以 64 位为准）；32 位注册失败只记入日志，不影响 64 位程序使用。32 位输入法读取上一级目录的词库和设置程序。卸载时两者都注销。安装界面的清单为 `highestAvailable`：管理员打开时即完成提权，内层包随之以管理员身份运行，不再二次弹窗；标准用户打开时不提权，由内层包在安装时请求管理员凭据，用户启用仍落在当前登录的账户。升级先验证新 DLL，失败时尝试恢复原有注册。每个版本装在自己的 `releases\<版本>` 目录，升级不会碰到正在使用的旧文件；重新安装同一版本时，正在被程序使用的文件（每个有输入框的程序都加载了 `LocalPinyinIME.dll`，打开的设置程序也占着自己的文件）先改名为 `*.<时间>.old` 挪开，下次重启时删除：已经打开的程序继续用旧文件，之后打开的程序用新文件；安装没有完成时，挪开的文件改回原名。卸载仅在注册仍指向该版本时移除 TSF 注册，个人词库和学习记录保留。

剪贴板记录程序 `LocalPinyinClipboard.exe` 只在用户开启剪贴板记录后运行，并把自己写进当前用户的登录自启项（`HKCU\...\Run\LocalPinyinClipboard`）。安装完成时，安装界面以普通权限运行新版本的它（`--replace`：关掉旧版本的记录程序再接替；没有开启记录时立即退出，所以自启项会指向新版本的文件夹），再运行设置程序 `--first-run`：还没回答过是否记录剪贴板时打开设置询问，否则直接退出。卸载时 `--uninstall` 让它退出并删除自启项，已保存的记录和其他个人数据一起保留。
