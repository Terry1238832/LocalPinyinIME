安装器封装原生输入核心、注册助手、设置桥接、四份输入数据及Electron设置程序和必需运行时，保留项目与第三方许可。运行 `scripts/Build.ps1` 完成原生测试、React/Vite编译和Electron封装，再生成版本配置并编译此Inno Setup脚本。

机器级 TSF 注册使用管理员权限；用户启用与验证通过原始用户运行。32 位应用（如 QQ 音乐）只从 32 位注册表视图加载输入法，所以包内另有 `x86\LocalPinyinIME.dll` 和 32 位的注册工具：安装时先由它在 32 位视图中注册并验证，再注册 64 位输入法（共享的输入法配置以 64 位为准）；32 位注册失败只记入日志，不影响 64 位程序使用。32 位输入法读取上一级目录的词库和设置程序。卸载时两者都注销。安装界面的清单为 `highestAvailable`：管理员打开时即完成提权，内层包随之以管理员身份运行，不再二次弹窗；标准用户打开时不提权，由内层包在安装时请求管理员凭据，用户启用仍落在当前登录的账户。升级先验证新 DLL，失败时尝试恢复原有注册。卸载仅在注册仍指向该版本时移除 TSF 注册，个人词库和学习记录保留。
