# 第一方短词扩充批次 001、002

本目录保存本次直接编写的候选词条和作者工具，供主词库合并前审核。没有导入第三方输入法词库、网络文章词表、用户输入或测试句子；没有把整篇文章或完整测试句子写成词条。拼音由作者辅助工具 pypinyin 生成后，按多音字风险检查并加入显式读音覆盖。该库仅用于编写阶段，不进入输入法运行组件。

`lexicon_batch_001.tsv` 面向常见动作、状态形容词、副词、连接词、数量、时间、动词补语，以及可重复使用的日常问答片段。优先补入“随便”、随/便常用搭配和其他缺失的普通短词。

`lexicon_batch_002.tsv` 面向居家物品、衣物和个人用品、购物与办事、工作学习、软件设备、地点交通，以及普通叙述常用的描写词。条目逐个编写；数量短语只使用实际常用的数词量词组合，没有用任意对象的笛卡尔积扩充体积。

每个有效数据行只有三列：

```text
pinyin<TAB>中文词语<TAB>relative_frequency
```

`# category:` 行记录语义分组。拼音只含小写 a–z；词语为实际候选显示文本。频率是本项目人为选择的相对排序权重，不是外部语料统计。普通专业和物品词约 5,000–5,500，常用动作/状态约 6,000–7,000，功能词和基本高频词约 8,000；“随便”等重点常用词为 9,000，部分相对少用的词另降权。

两个批次按 `(pinyin, word)` 去重：001 对照当前 core 和 local_core；002 同时对照上述两份词库和 001。已有的“忘记”“放松”“收拾”“终于”“冬天”等正确键不会重复加入。少量具有独立正确读音的多音词可以以不同拼音键保留。

已显式核对的风险包括“多长时间”的长 chang、“睡不着/用得着”的着 zhao、“得了”补语的了 liao、“重连/重命名/重置/重做”的重 chong、“长裙/长靴”的长 chang。第二次官方词典复核纠正了“简朴”jianpu、“调班”diaoban、“调课”diaoke；“调休”保留 tiaoxiu。其他多音词按词义审核，例如工作同业的“同行”用 tonghang，软件重新加载的“重载”用 chongzai。

各批次 JSON 保存数量、类别、长度分布、输出 SHA-256 和去重基准词库 SHA-256。生成工具只写本目录的批次 TSV/JSON，不修改主词库或元数据。批次合并后请保留这些输出作为编写存档；重新针对已合并词库运行会自然过滤已加入条目，不能直接覆盖原始批次。

作者工具示例（在源码根目录；依赖临时目录由主任务准备）：

```powershell
$env:PYTHONPATH = (Resolve-Path .\.build\authoring-deps).Path
python .\resources\dictionary\expansion\build_lexicon_batch_001.py --batch 001
python .\resources\dictionary\expansion\build_lexicon_batch_001.py --batch 002
```

这些词条已经完成格式、重复键和常见多音字检查，并不等于每个词条都已完成正式语言学审校。主词库最终排序、拼音歧义和文章输入覆盖需要由独立的合并与回归流程验证。
