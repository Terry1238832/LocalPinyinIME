# 第一方短词扩充批次 003

本批次直接编写食材、家常菜、厨房用具、烹饪动作、家务收纳、园艺与自然景物、常用描写词及可复用四字表达。逐项选择实际会使用的词语，没有生成任意对象的组合，也没有把文章或完整测试句子写成词条。

输出只含 2–4 个汉字，格式为 `pinyin<TAB>word<TAB>relative_frequency`。词条相对权重为 5,500 或 6,000，是本项目人为选择的排序层次，并非语料频率。批次源代码包含未入库候选，重复词、已有词的不同自动读音、超过四字的表达和作者认为不自然的形式都被排除。

本批次同时对照 core、local_core、standard 和 001/002 去重。为了避免自动生成读音把已经存在的词重新加入，本批次也排除已有显示词的不同拼音；真正的旧词读音修正应另行审核。JSON 保存具体数量、类别、长度分布、输出哈希和去重基准文件哈希。

pypinyin 仅用于编写阶段辅助生成读音，不进入运行时。作者逐类浏览完整新词输出并核对多音字，已修正默认辅助读音中“鸡爪/卤鸡爪/蟹爪兰”的 zhao、“肋排”的 le、“圆茄”的 jia、“味醂”的 lan、“牛轧糖”的 ya、“粘乎乎”的 zhan，以及烘焙名词“蛋糕模/面包模”的 mo。其他显式读音覆盖包括“和面机”的 huo、“饧面”的 xing、“薄芡/擀薄”的 bao、“重峦叠嶂”的 chong、“草长莺飞/生长期”的 zhang。

“粘锅”保留普通话动词用法的 zhan；“不粘锅”的常用读音保留 nian。“脱模/入模”采用工艺术语常用的 mo，独立烘焙模子名词采用 mu。读音审阅是本项目贡献者审阅，不代表已逐字通过正式语言学审校。少量地域表达，如“嗦粉”“钵钵鸡”“辣子鸡”，是可复用日常词语。

复现作者工具时需从源码根目录把临时 `.build/authoring-deps` 加入 PYTHONPATH。作者工具只写本目录 003 的 TSV/JSON，不修改正式词库。正式词库合并本批次后，重新运行会过滤已合并词语，因此不要用合并后的基准覆盖冻结的批次文件。

“味醂”的 lin 读音核对来自[教育云线上字典](https://pedia.cloud.edu.tw/Entry/Detail?title=%E9%86%82)；“肋”的口语 lei 读音可参考[教育部重编国语辞典](https://dict.revised.moe.edu.tw/dictView.jsp?ID=3260&la=1&powerMode=0)。这些页面仅辅助核对读音，没有导入其词表或解释文本。
