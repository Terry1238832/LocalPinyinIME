# 原创后文联想表

continuations_zh.tsv 是独立的短后文建议表，使用 UTF-8 三列：`prefix<TAB>next_text<TAB>weight`。注释以 `#` 开头。前缀仅汉字，长度 2–8；后续仅汉字，长度 1–8；权重 100–10,000。当前冻结 346 个不同映射、117 个不同前缀，覆盖日常计划、天气状态、礼貌关心、聊天回复、办公文档、工作进度、时间约见、购物饮食、出行到达和连接表达十类。

每组前缀和后续选项由贡献者单独编写，不从文章、第三方词库、商业输入法或私人聊天记录提取，不将完整测试答案用于造候选。例子包括“我想”→“去／看看／试试”，“今天天气”→“不错／很好”，“辛苦”→“了／你了／大家了”。同一前缀的多个正常后续并存。权重是作者对普通使用场景的相对偏好，不是实际语料词频。

作者脚本 build_continuations.py 重建数据及独立 metadata，并检查字段、长度、汉字范围、权重、重复键、所有冻结 typing TSV 的完整答案及前缀和后续合并结果。metadata 保存 TSV 与作者脚本 SHA、类别和长度统计、固定文本文件哈希；许可证和作者来源另见 continuations_sources.json。数据采用项目 MIT 许可证，运行时无需 Python、网络或作者依赖。

这个文件与 context_zh.tsv 的字符统计模型分开维护，增加后文建议不会改写既有模型。匹配和候选上屏由 C++ 实现；此处只提供经过复核的固定数据。表达可能有多个合乎语境的后续，因此不把一条建议当作对句子意图的确定判断。
