# 本地拼音 0.7.9

Windows 10/11 x64离线中文拼音输入法。输入核心是原生C++20/Windows TSF，设置使用Electron、React、TypeScript和Vite。关闭设置后桌面程序退出，输入核心继续独立工作。安装包自带运行时，使用时无需联网或另外安装Node.js、Python。

本轮新增12,404条生活、网络交流、家庭用品、数码与出行词语，内置有效词库共209,306条。原创补词逐项核对拼音、三层去重及原生候选验证，旧词条和拼音保留；按独立清单提高118项常用词优先级，其余旧权重保持；少数同音词仍可能超出前九候选，长句和同音输入仍需选词。

本轮新增词的最终原生前九覆盖为12,404/12,404，首选8,360；同一引擎回放旧词库分别为7,676和4,633，见[新增词对照](docs/new-word-comparison-079.json)。267句公开整句回放首选154句、前九203句，旧数据分别为154句和203句，见[排名变化](docs/lexicon-079-rank-changes.json)。32句开发场景回放前九25→25，见[补充回放](docs/scenario-replay-079.json)。这些是公开开发验证，仍需选词，不代表所有长句和应用；未做独立人类语言编辑验收。

常用词排序：按用户要求，给118项常用词设置独立的工程优先级；“和”“添加”在隔离个人数据的默认查询中排在首选。36项单词检查首选21→36，9项带前文检查首选5→5，见[常用词排序对照](docs/common-word-priorities-079.json)。优先级不是语料频率或使用占比；个人词库和本地学习仍会参与排序。带前文的同音词判断仍需改进，不能据此声称整句都能直接命中。

本轮对固定0.7.8数据的267句回放，首选与前九命中记录均未变化。完整候选和排名变化保留在[整句记录](docs/lexicon-079-rank-changes.json)。本轮保留原引擎排序逻辑；118项常用词优先级在对照测量前确定，没有按公开句子结果逐项调权或补入完整测评答案。

最终仍有已错误首选的文字变化：267句字符错误率0.0759→0.0763；32句场景字符错误率0.0777→0.0855。“他只得张着小嘴”的错误首选由“他值得长着小嘴”变为“他指的长着小嘴”；“外卖不放香菜酱料请分装”的正确答案由第7降到第8，错误首选也变差。见[完整候选变化](docs/lexicon-079-top-candidate-changes.json)。命中数持平不等于所有句子的候选文字和质量不变。

候选栏只显示一行，按字号和窗口可用宽度分页，左右箭头或窗口箭头切换。每页数字从1重新编号，空格接受当前页选中的候选；长词省略显示但完整上屏。设置页的拼音与联想预览也使用单行分页。

前文联想：继续打拼音时参考当前光标前的文字排序；词语上屏后，用346条原创联想关系、词库短语和已有选词学习补全后续词。按Tab接受联想、Esc关闭，空格和数字保留普通编辑行为。“输入”设置可关闭联想，也能在试用区查看真实结果。使用说明见[前文联想](docs/CONTEXT_PREDICTION.md)。

设置保留原蓝色PI品牌和侧栏图标、明暗主题、七档字号、真实候选预览、Shift切换、个人词库增改删查、内置词库查询与学习清除。五页保持挂载，切换保留输入状态；启动先读取保存主题和配置。

从[GitHub Release v0.7.9](https://github.com/Terry1238832/LocalPinyinIME/releases/tag/v0.7.9)下载[Windows x64安装包](https://github.com/Terry1238832/LocalPinyinIME/releases/download/v0.7.9/LocalPinyinIME-0.7.9-x64.exe)（101.35 MiB）及同页SHA-256文件。安装内容约330.95 MiB，仅保留中文与英文运行时语言资源。双击安装后按Win＋空格选择“本地拼音”；升级后重新打开输入应用。

普通拼音候选使用空格确认当前选项、数字1–9选择当前页对应词、左右箭头翻页、Esc取消、Enter提交原始拼音；Ctrl＋Space切换中英文。支持全拼、连续拼音与整句候选、简拼、补全、单次拼写容错、中文标点、鼠标选词和本地学习。长句和同音词仍可能需要选词。

## 构建

需要Visual Studio C++工具和Windows SDK、CMake/Ninja、Python 3、Node.js 22.12或更高版本及Inno Setup 6。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build.ps1
```

脚本构建并验证原生组件、按npm锁文件安装作者依赖、编译Vite与Electron、打包桥接和五份运行数据，生成dist中的安装包及校验文件。首次需要联网下载依赖和Electron；官方校验后的缓存压缩包可重用。desktop中运行npm ci及npm run dev开发设置页，原生桥接须先构建。数据生成统一UTF-8/LF，当前SHA与Git检出一致。

## 数据与验证

个人设置、词库和学习沿用%LOCALAPPDATA%\LocalPinyinIME；Electron缓存在desktop子目录。学习最多保存2,048条记录；清除学习保留个人词库，卸载保留个人数据。前文查询和试用在本机完成，接受联想不新增学习记录，普通拼音选词沿用原有学习。

34项原生回归通过（含10个跨进程桥接场景），实际交付ASAR通过15个桌面流程、80次侧栏切换及41张截图检查。267句公开回归首选154/267、前九覆盖203/267，结果见[输入质量记录](docs/lexicon-079-quality.json)；新增原创词逐项原生查询与上游名称审计分开记录。新增词作者与结构审计见[词库审计](docs/lexicon-079-authoring-audit.md)。完整验证见[verification.json](docs/verification.json)和[兼容范围](docs/COMPATIBILITY.md)。未完成干净机器完整安装卸载和全部应用的安装后验收。
